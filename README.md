# SuperMail

SuperMail is an autonomous Gmail secretary project for secure read, reason, act, and audit workflows over a real mailbox.

This repository is being built as an agentic engineering system:

- ChatGPT owns architecture, sequencing, review, and escalation policy.
- Google Jules implements dependency-ordered roadmap issues.
- CI proves the repository remains healthy.
- Completed PRs enter an AI-review handoff automatically.
- Human review is an exception path rather than the normal development loop.

> Foundation stage only. No Gmail credentials, OAuth tokens, mailbox access, or autonomous sending are implemented yet.

See AGENTS.md and docs/AGENT.md for the operating contract.
